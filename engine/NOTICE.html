The engine: licences and source

busytex.js and busytex.wasm are one program: pdfTeX from TeX Live, compiled to WebAssembly with the build scripts of BusyTeX and with Emscripten. lazytex distributes this program under the GNU General Public License, version 3 or (at your option) any later version (licenses/GPL-3.0.txt). pdfTeX is under GPL-2.0-or-later, which permits this.

The source

The corresponding source of this build:

  • TeX Live source: @texliveSource@
  • BusyTeX's build scripts: https://github.com/busytex/busytex/tree/@busytex@
  • Emscripten @emscripten@, from nixpkgs
  • lazytex's build of the engine (engine/default.nix, with the pins in flake.lock): https://github.com/RandomSpaceship/lazytex, at the commit of the release that has this file

A build of the engine changes no file of TeX Live or BusyTeX. engine/default.nix says which settings it gives to BusyTeX's Makefile.
